# autotouch

autotouch is a tiny always-on mac agent for two trackpad gestures: three-finger swipe left opens chrome, three-finger swipe right hides the app under the pointer. no settings, no dock or menu bar icon, no permissions to grant, and zero dependencies.

```sh
brew install --cask lingrino/tap/autotouch
open -a Autotouch   # once: installs the background agent
```
